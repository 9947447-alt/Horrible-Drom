# 熄灯之后：反应 / Horrible Dorm: Reaction

> 化学幻想宿舍生存塔防。躺平冷凝梦能，用酸与反应链把噩梦滴定到天亮。

## 怎么玩

```bash
npm start
# 打开终端输出的 http://127.0.0.1:8787
```

没有构建步骤，也没有 npm 依赖。也可以用任意静态服务器指向项目根目录；请勿直接双击 `index.html`（ES Modules 需要 HTTP）。

单局时长：简单约 6 分钟、普通约 8 分钟、噩梦约 9.5 分钟。

## 核心循环

1. 选一间宿舍：房间面积不同，并自带一个起始道具。
2. 躺上冷凝床：每秒产出梦能，层析仪产出试剂。
3. 建造酸系炮台、氯酸钾炮台、苯炮台与功能设备；相邻装置会自动形成反应链。
4. 梦魇在门外挠门并升级，最晚 Lv.14；撑到天亮或击杀全部活跃梦魇即可获胜。
5. 气密门被打破即失败。

## 操作

| 输入 | 作用 |
|---|---|
| 鼠标/触屏 | 选房、查看建筑、在 Canvas 上放置 |
| 1–0 | 建造栏对应卡片 |
| Q | 应急喷淋 |
| R | 维修气密门 |
| Space | 暂停/继续 |
| Esc / 右键 | 取消建造、关闭面板 |
| 滚轮/触屏滚动 | 建造栏、图鉴内容 |

## 内容

- **6 间宿舍**：不同尺寸、起始道具、装饰气质。
- **酸系主炮**：硅酸 → 碳酸 → 盐酸 → 硫酸 → 次氯酸 → 高氯酸；每阶段 I–III，已解锁阶段可直接建新塔。
- **特化炮台**：氯酸钾 I–X、苯 I–X，数量不设上限，受格子与资源限制。
- **功能设备**：层析仪、冷凝器、通风柜、催化台、中和池、加速器、梦能取款机；加速器/取款机各限 2 座，其余不限。
- **6 种梦魇**：苯环幽影、白磷鬼火、汞形怪、硫化氢瘴气、一氧化碳潜影、甲醛标本；等级 1–14。
- **6 条反应链**：催化氧化、低温凝析、电磁淬火、爆鸣氧化、芳烃共振、中和屏障。
- **三档难度**：简单 / 普通 / 噩梦（噩梦 04:00 追加第二只梦魇）。
- 图鉴、教程、设置、暂停、结算、本地存档。

## 项目结构

```
index.html            入口
src/main.js           启动
src/core/             存储、WebAudio
src/app/controller.js 控制器：输入/循环/界面/渲染集成
src/content/          房间、炮台、设备、梦魇、反应、难度数据
src/game/             无 DOM 的游戏模拟（经济、战斗、梦魇 AI、压力、结算）
src/ui/               DOM 界面
src/render/           Canvas 等距渲染
styles/               视觉样式
tests/                node:test 逻辑与内容测试
tools/serve.mjs       零依赖静态服务器
tools/shot.mjs        Chrome headless 截图工具
docs/CONTRACT.md      模块契约
```
