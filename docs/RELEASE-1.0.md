# v1.0.0 发布说明

发布日期：2026-10-25。

《熄灯之后：反应 / Horrible Dorm: Reaction》首个正式版本。

- 六间宿舍、三档难度，包含噩梦双魇模式。
- 六阶段酸系主炮、两类特化炮台、七类功能设备、六条反应链。
- 六类梦魇、舍友灯态、床门经济、教程、图鉴、设置、暂停与结算。
- 包含床门升级报价与实际扣费一致性修复，以及击杀胜利结算文案。
- 纯静态网页，无运行依赖，无构建步骤，存档保存在浏览器本地。
