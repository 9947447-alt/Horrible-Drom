# 设计方向 v1 —《熄灯之后：反应》

## 视觉世界

**关键词**：熄灯后的化学系旧宿舍 / 暖灯与冷走廊 / 实验记录本 / 墨色梦魇 / 手作感。

不是霓虹赛博实验室，也不是卡通手游。想象一座 90 年代大学宿舍：木地板、绿墙裙、上下铺、搪瓷杯、暖水瓶、旧风扇、沾着试剂渍的实验台。门外走廊是冷青色的，灯管闪烁。梦魇是化学恐惧的具象：苯环、磷火、汞滴、瘴气、潜影、标本罐，全部以黑墨和呼吸般的微光呈现。

## 色板

| Token | 值 | 用途 |
|---|---|---|
| ink | `#0b111b` | 基底、背景、深阴影 |
| ink-2 | `#131c2a` | 面板、墙体 |
| paper | `#f3e7cf` | 主文字、纸卡 |
| paper-dim | `#cbbca2` | 次级文字 |
| amber | `#ffc75a` | 梦能、暖灯、主要操作 |
| amber-deep | `#b97a2d` | 琥珀阴影 |
| reagent | `#63e0c2` | 试剂、正向反馈、可交互 |
| alarm | `#ff6b57` | 危险、门破损、大按钮 |
| ghost | `#8c9aa8` | 走廊、幽灵信息 |
| frost | `#8fd8ff` | 冷、克制、选中态辅助 |
| toxic | `#d7e36b` | 硫雾、毒气警告 |

梦魇各自有识别色，但 UI 的语义色保持稳定：琥珀=资源/暖，青=可操作/反应，珊瑚=危险，纸白=信息。

## 字与形

- 标题：系统可用的手写/圆体优先（Hannotate SC、Yuanti SC、PingFang SC），字重 800，字距微开。
- 正文：PingFang SC / Hiragino Sans GB / Microsoft YaHei。
- 数字：ui-monospace / SFMono-Regular / Menlo，使用 tabular figures。
- 形：纸卡、胶带、旧印章、手写批注、危险斜纹；边角 2–8px，不做大圆角胶囊堆叠。
- 图标：内联 SVG 线稿 + 少量填充色，禁 Emoji。

## 屏幕与信息架构

1. **主菜单**：夜色宿舍楼立面（CSS 绘制）、亮灯窗户、慢速雾。标题在左上/中心；右侧竖向菜单。底部显示版本/标语；本机战绩已存储于 localStorage，v1 暂不单独展示。开始守夜 → 难度选择/选房。
2. **选房**：楼层剖面或 6 张房卡。每张卡显示房间号、面积、起始道具、气质描述、起始难度；选房后直接进入对局。今晚梦魇 preivew 放在侧边。
3. **对局 HUD**：
   - 顶部：夜钟 + 阶段、夜魇等级/血条（最多两条）、技能节点、梦能/试剂。
   - 左侧：舍友灯态、事件流（收合）。
   - 右侧：冷凝床/气密门、维修/升级、应急喷淋；威胁值已计算但 v1 未单独展示。
   - 底部：建造 dock，分炮台/设备两组；建造模式提示。
   - 中央：Canvas 场景，绝不让面板覆盖房间中心。
4. **检查面板**：点击场景建筑后从右侧滑出，显示名称、阶段/等级、伤害类型、升级/进阶/拆除。
5. **暂停/设置/图鉴**：暂停用“值班记录”卡片；图鉴用实验记录本，包含梦魇、建造目录、反应链、操作。
6. **结算**：夜色褪成黎明或彻底黑掉；大评级印章、夜钟、伤害/金币/舍友统计、再来一局/换房。

## 动效与声音

- 动效：面板 160–220ms ease-out；按钮按下 60ms；危险脉冲 1.2s；不使用持续旋转/漂浮的无意义动画。
- 降低动效：`prefers-reduced-motion` 和 UI 开关同时生效。
- 声音：WebAudio 合成夜噪/低鸣/金币/建造/挠门/心跳/警报/天亮。音量与静音持久化。

## 可访问性与响应式

- 键盘可完成建造选择、升级、暂停、帮助等核心操作；画布上的格子选择/放置需要指针或触屏（键盘网格选格列为后续改进）。焦点环清晰；所有热键可在图鉴查看。
- 1280×720 起；1440×900/1920×1080 为视觉目标；移动端横屏 844×390 可玩，竖屏提示旋转。
- 颜色不是唯一信息载体：弱点/抗性同时有图标和文字；低血警告同时有视觉与声音。
- 中文最小字号 12px；重要信息 ≥14px；对比度达到可读。
